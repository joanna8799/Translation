## 1. 產品基本資料

- 開發者 NGUYEN DANH HAO（越南獨立開發者），iOS App Store id 6759873531，2026-04-21 上架，官網 easycomix.app。
- 目前只找到 iOS 版。Google Play 上沒有找到同一開發者的版本。
- 定位：漫畫、韓漫、條漫、國漫翻譯，翻譯結果直接畫回對話框裡，保留原本的閱讀節奏。
- 起因（貼文開頭）：想看某部漫畫但只找得到韓文或日文生肉，一般翻譯 app 對漫畫字型與直式文字效果很差。
- 亮點：漫畫專用 OCR（針對漫畫字型、直式日文、狀聲詞訓練，每種文字各一個辨識器）、Live Translation 邊捲邊翻、Live Captions 在其他 app 上方顯示翻譯、iOS 捷徑。

## 3. 六個成本控制手法

### 3.1 免費層完全在裝置上跑，邊際成本為零

「無限離線翻譯」是整個模式的關鍵。OCR 模型跑在手機上；翻譯用 iOS 系統的 Translation framework（iOS 17.4 起開放給第三方 app，免費、離線、不需要 API key、模型與系統翻譯 app 共用）。

所以免費用戶翻一萬頁，開發者的伺服器帳單是零。他可以放心把免費層寫成「無限」，因為根本沒有帳單。

推測：OCR 是自訓模型轉 CoreML；翻譯是 Apple Translation framework。理由是「27 種語言離線」與 Apple 翻譯支援的語言清單高度重合，而且 iOS 17.4 以上才開放此 API，剛好對得上 app 的最低系統需求。

### 3.2 唯一有邊際成本的東西是 LLM，所以只有它被限額

- 每日 10 次，而且必須登入。登入不是為了收集資料，而是把額度綁在帳號上（Sign in with Apple 對開發者免費），免費額度才不會被無限刷。
- 沒有廣告。廣告收入抵不過 LLM 成本，還會拖慢 app、影響評分。乾脆不放，用 Pro 收錢。

### 3.3 雲端只收文字，不收圖片

因為 OCR 已經在端側做完，送到 LLM 的是「這一頁的十句對白」，不是一張圖。

- 純文字：一頁約 300 到 600 token（含系統提示）。
- 送圖片：一張圖光是 image token 就 260 到 1,600 不等，還必須用有視覺能力的模型，更貴更慢。

這一步把每頁成本壓低一個數量級，同時避免把有版權的圖片上傳到第三方 API，隱私與法律風險都降低。

### 3.4 逐頁翻，不整章翻

免費用戶只能「捲到哪翻到哪」。使用者常常一章看一半就關掉，逐頁翻就不會浪費沒看到的頁面。整章預翻是 Pro 才有的功能。

### 3.5 用訂閱制把 LLM 成本變成可預測的收入

- 週訂閱對「追一部漫畫追完就走」的使用者轉換率高，而且每週續訂的平均收入遠高於月訂或年訂。
- 一個 Pro 用戶每月讀幾百到幾千頁，用純文字 LLM 的成本是幾美元以內（見 [03-architecture-and-cost-model.md](03-architecture-and-cost-model.md) 第 5、6 節），訂閱費可以覆蓋。

### 3.6 功能分層跟著成本走

- 「故事背景／上下文翻譯」：prompt 更長、需要較好的模型，所以放 Pro。
- 「只能靠 AI 的 7 種語言」：沒有離線引擎可退，所以放 Pro。
- Live Captions、系統捷徑：技術上難做、有差異化，所以放 Pro。

規則就是：只要這個功能會讓伺服器花錢、或是很難做，就放進 Pro；免費層只放邊際成本為零的東西。

## 4. 推測但未證實的部分

- 是否有跨使用者的翻譯快取（同一頁被很多人翻，只付一次 LLM 費用）。公開資訊沒提，但這是我們自己做時最值得加的東西。
- LLM 供應商未公開。從「每日 10 次」的慷慨程度推測是低價模型（Gemini Flash 級或同級）。
- 「畫回氣泡」的擦字方式未公開。可能是輕量 inpainting 模型，也可能是像 MangaLens 那樣用氣泡自身的紙色填滿（不需要模型）。

## 5. 對比：沈浸式翻譯的漫畫功能

| | EasyComix | 沈浸式翻譯（漫畫功能） |
|---|---|---|
| OCR 位置 | 端側 | 雲端（自家伺服器） |
| 免費額度 | 離線無限；AI 每日 10 次 | 登入後每月 100 頁 |
| 付費 | 週／月／年訂閱 | Pro 約 ¥69/月（年付較低），Pro 每月 20M token，更高一級 50M token |
| 覆蓋範圍 | 手機上任何 app（iOS 用折衷方式） | 80 到 100 個白名單漫畫網站，只在瀏覽器內 |
| 手機 | iOS app（Live Captions／捷徑） | iOS Safari 擴充；Android 要用支援擴充的瀏覽器 |
| 圖片修復（inpaint） | 有 | 有 |
| 自帶 API key | 未公開 | 有 |

沈浸式翻譯把整個漫畫功能鎖在 Pro 後面，用「每月 100 頁」當試用鉤子；他們的 OCR 在自家伺服器，所以每一頁對他們都有成本，必須限量。

EasyComix 反過來：把免費做到「夠用」，只有品質更好的 AI 才需要付費。對獨立開發者這個模式更省錢，因為免費用戶幾乎不花伺服器錢，而且沒有 GPU 機器的固定成本。

## 6. 我們該學什麼、該加什麼

學：
- 辨識放端側、雲端只收文字。
- 免費層用系統或端側翻譯引擎，邊際成本為零。
- LLM 額度綁帳號，每日硬上限。
- 週訂閱。

加：
- 跨使用者共享翻譯快取。
- 自帶 API key（BYOK）選項，重度用戶自付。
- Pro 也設合理上限（例如每月 3,000 頁後降級到便宜模型），避免單一用戶把 API 刷爆。
- Android 版，這是 EasyComix 目前沒有、而且「任何 app 內」真正做得到的平台。
